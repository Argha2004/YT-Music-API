About The Project

Architected for Developers & Music Innovators

A fast, reverse-engineered REST API empowering developers to build custom music players, streaming bots, radio recommenders, and catalog exploration tools without official API restrictions.

The Vision & Why This Exists

Google's official YouTube Data API v3 enforces severe constraints: strict 10,000-unit daily quotas, cumbersome OAuth setups, a complete lack of audio-streaming support, and missing rich music context (such as album hierarchy, related artist graphs, and automatic radio playlists).

YouTube Music REST API solves these challenges by interfacing directly with Google's internal YouTubei/Innertube client protocol. It provides clean, standardized JSON endpoints for all catalog entities and pairs them with an integrated Range-enabled streaming proxy capable of bypassing Google CDN 403 Forbidden barriers.

Core Technical Architecture

Innertube Protocol Engine

Bypasses standard web scraping using native YouTubei Protobuf endpoints. Communicates using mobile Android & Web client signatures for instantaneous metadata retrieval with 99.9% uptime.

HTTP 206 Byte-Range Audio Proxy

Handles seamless audio streaming directly to HTML5 <audio> tags, mobile apps, or Discord bots. Supports seekable partial byte requests with automatic fallback to piped process streams.

Auto Radio & Queue Generation

Pass any track's 11-character video ID to /api/radio/:videoId to receive an endlessly contextual queue of related music, tailored by YouTube Music's real-time recommendation algorithms.

Zero-Bloat Native Node.js

Engineered with native Node.js HTTP servers, ES Modules, and zero heavyweight web frameworks. Delivers ultra-low latency, sub-millisecond route dispatching, and microscopic RAM footprint.
