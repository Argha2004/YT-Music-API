YouTube Music REST API Documentation

A high-performance, developer-friendly REST API built directly on top of Google's YouTube Music Innertube protocol with full HTTP 206 Partial Content audio streaming support.

Base URL & Setup

All endpoints are served from the local or deployed host:

Base URL 
http://localhost:3000
CORS Enabled: Cross-Origin Resource Sharing (CORS) is enabled by default for all origins (*), allowing seamless integration with web browsers, Electron, Flutter, and React Native apps.

Streaming Audio Proxy (HTTP 206)

GoogleVideo CDN audio links are strictly IP-bound and protected by BotGuard/PO-Token verification. This API provides an integrated streaming proxy at /api/stream/:videoId that forwards HTTP Range byte requests seamlessly.

Zero 403 Errors: The stream proxy uses the Android Innertube profile with automatic fail-safe process streaming to bypass GoogleBot restrictions, providing fast, continuous streaming.
Platform / Language Implementation Example
HTML5 Web Player <audio src="http://localhost:3000/api/stream/3_g2un5M350" controls></audio>
Flutter (just_audio) player.setUrl('http://localhost:3000/api/stream/3_g2un5M350');
React Native / Expo Audio.Sound.createAsync({ uri: 'http://localhost:3000/api/stream/3_g2un5M350' });
VLC / Media Player vlc http://localhost:3000/api/stream/3_g2un5M350
cURL / Download curl -N "http://localhost:3000/api/stream/3_g2un5M350" --output song.mp4
GET /api/search
Try in Playground →
Performs filtered catalog searches across YouTube Music with full track metadata, artists, album names, duration, thumbnail URLs, and ready-to-stream URLs.
Parameter Type In Required Description
q string query Required Search keyword or query (e.g. "Starboy", "Hans Zimmer").
filter string query Optional Category filter: songs, albums, artists, or playlists. Default: songs.
limit integer query Optional Maximum number of results to return. Default: 20.
Sample Request & Response

GET /api/stream/:videoId
Stream Test Song →
Streams real-time high-quality audio with HTTP 206 Partial Content (Range bytes) support for fast buffering and instant seeking.
Parameter Type In Required Description
videoId string path Required The 11-character YouTube video ID (e.g. 3_g2un5M350).
Range string header Optional Standard HTTP Range byte header for seeking (e.g. bytes=0-100000).
Sample Range Request 
// HTTP Request
GET /api/stream/3_g2un5M350 HTTP/1.1
Host: localhost:3000
Range: bytes=0-1000

// HTTP Response
HTTP/1.1 206 Partial Content
Content-Type: video/mp4
Content-Range: bytes 0-1000/2182350
Content-Length: 1001
Accept-Ranges: bytes
Cache-Control: no-cache

GET /api/playlists/:playlistId
Fetches full playlist metadata, curator name, cover art, and ordered tracks.
Parameter Type In Required Description
playlistId string path Required Playlist ID (e.g. RDCLAK5uy_k... or standard YouTube playlist ID).
limit integer query Optional Maximum tracks to retrieve. Default: 100.
GET /api/albums/:albumId
Retrieves album details including album title, release year, artist, high-res artwork, and complete tracklist.
GET /api/artists/:artistId
Retrieves artist details, biographical summary, banner/avatar images, and top 10 songs.

Authentication (User Account)

Searching and audio streaming are 100% public and do not require authentication. For user account actions (Liked Songs, History, Like/Unlike), send your session cookie in the x-yt-cookie request header.

Sample Authenticated Request 
curl -X GET "http://localhost:3000/api/account/liked" \
  -H "x-yt-cookie: SAPISID=YOUR_SAPISID_COOKIE_HERE; __Secure-3PAPISID=...;"
GET /api/account/liked
Returns the authenticated user's Liked Music playlist (requires x-yt-cookie header).
GET /api/account/history
Returns the authenticated user's recent listening history (requires x-yt-cookie header).
POST /api/account/like/:videoId
Likes a track on the authenticated YouTube Music account. Use DELETE /api/account/like/:videoId to remove the like.

HTTP Status Codes

Status Code Meaning Description
200 OK Success Standard success response for search, metadata, and full audio streams.
206 Partial Content Range Success Returned by /api/stream/:id when a client provides a Range header (seeking/buffering).
400 Bad Request Invalid Request Missing required parameters (e.g. q search parameter).
404 Not Found Not Found Track or playlist does not exist, or video is deleted/unavailable on YouTube.
500 Server Error Internal Error Unexpected server error or unhandled upstream failure.
