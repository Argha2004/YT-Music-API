How Users Stream Songs Using the API

Every track returned in the JSON payload contains a streamUrl property (e.g. /api/stream/{id}). External apps, mobile apps, or web music players stream audio directly from this endpoint:

GET http://localhost:3000/api/stream/{videoId}
HTML5 Web Player: <audio src="http://localhost:3000/api/stream/{id}" controls></audio>
Flutter (just_audio): player.setUrl('http://localhost:3000/api/stream/{id}');
React Native / Expo: Audio.Sound.createAsync({ uri: 'http://localhost:3000/api/stream/{id}' });
VLC Media Player: vlc http://localhost:3000/api/stream/{id}
